PlatformSatisfiedBy(TDPMPlatform, TDPMPlatforms)

Returns true when a package built for one of the platforms in available can satisfy a project target of wanted . This is a plain set membership test, except that Win64 and Win64x are treated as interchangeable (their binaries are compatible both ways), so a Win64-only package satisfies a Win64x target and vice versa.

ResolveCompatiblePlatform(TDPMPlatform, TDPMPlatforms)

Returns the platform from available whose binaries should be used to satisfy a target of wanted . Returns wanted when it is directly available; otherwise, because Win64 and Win64x produce interchangeable binaries, returns the Win64/Win64x counterpart when it is available. Falls back to wanted when nothing compatible is present.
